Assignment 1 – What happens between typing a URL and seeing the page? When I type a URL into the browser and press Enter, the browser checks its cache and uses DNS to find the IP address of the website. It then connects to the server and sends an HTTP request. For HTTPS websites, a secure connection is established. The server processes the request and sends a response containing the HTML document. The browser reads the HTML and requests additional files such as CSS, JavaScript, and images. It then processes these files, arranges the content, and displays the webpage on the screen.
